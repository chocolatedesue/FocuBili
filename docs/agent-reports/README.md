# Agent Reports（内部）

本目录为 AI 代理的实现记录、缺陷修复说明与代码/产品评审，**仅供开发与协作内部参考，不是面向用户的产品手册**。

文件命名约定：

- `REPORT_*` — 分波次/专题实现报告
- `FIX_*` — 缺陷修复说明
- `REVIEW_*` — 评审与后续建议
